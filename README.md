# Usage See

Claude, Gemini, Codex 개인 구독의 5시간·주간 사용량을 한 화면에서 확인하는 macOS·Windows 데스크톱 앱입니다. 별도의 항상 위에 표시되는 위젯 창도 제공합니다.

## 실행

Node.js 22 이상에서:

```bash
npm install
npm start
```

앱의 **설정**에서 서비스를 연결하면 해당 서비스의 공식 사이트가 앱 창으로 열립니다. 로그인 후 사용량 화면을 연 상태에서 Usage See 대시보드의 **현재 화면 읽기**를 누르세요. Gemini는 사이트에서 **Settings → Usage Limits → Usage**로 이동해야 합니다. **위젯 띄우기**를 누르면 화면 위에 고정되는 작은 창이 열립니다. 위젯은 드래그하여 옮기거나 크기를 조정할 수 있습니다. 앱 창을 닫아도 트레이 메뉴에서 다시 열 수 있습니다.

## 패키징

```bash
npm run package:mac   # Apple Silicon macOS 앱
npm run package:mac-intel # Intel macOS 앱
npm run package:win   # x64 Windows 앱
```

결과물은 `dist/`에 생성됩니다. 배포용 서명·공증은 별도로 설정해야 합니다. Windows 패키지는 Windows에서, macOS 패키지는 macOS에서 실제 실행 확인이 필요합니다.

## 동작 원칙

- 서비스별 5시간·주간 한도를 분리해 보여줍니다. 서로 다른 서비스의 수치를 합산하지 않습니다.
- 각 사이트의 **현재 화면에 보이는 텍스트**에서 명확한 백분율·잔여량만 읽습니다. API 종량제 사용량, 토큰 수 추정치, 화면에 없는 수치는 사용하지 않습니다.
- 페이지 원문과 로그인 정보는 저장하지 않습니다. 최근 스냅샷과 연결 목록만 앱의 로컬 사용자 데이터 폴더에 저장합니다. 사이트 창은 앱 실행 중 메모리 세션을 사용하므로 앱 종료 후 다시 로그인해야 할 수 있습니다.
- 값이 없으면 `확인 필요`, 일부만 있으면 `값 일부 없음`, 로그인 화면이면 `로그인 필요`, 화면을 읽지 못하면 `페이지 변경`으로 표시합니다. 15분이 지났거나 읽기에 실패한 이전 스냅샷은 `오래된 정보` 또는 `이전 값`으로 표시합니다.
- 초기화 시각은 ISO 시각이나 명확한 상대 시간이 표시된 경우에만 현지 시간으로 바꿉니다. 그 외에는 원래 문구를 보여줍니다.
- 읽기에 실패해도 이전 스냅샷을 지우지 않습니다. 연결 해제 시 해당 서비스 스냅샷을 삭제하고, **전체 기록 삭제**는 모든 스냅샷을 삭제합니다.
- 앱 자체에는 계정 데이터나 사용량을 외부 서버로 전송하는 코드가 없습니다. 공식 사이트 창은 로그인과 화면 표시를 위해 해당 서비스에 직접 연결됩니다.

## 디자인 참고

`usage-mac`의 SwiftUI 위젯에서 좁은 서비스 카드, 경고색 막대, 확인 시각과 출처 표시를 현재 앱에 반영했습니다. 채택한 요소와 제외한 범위는 [디자인 검토](docs/usage-mac-review.md)에 정리했습니다.

## 검증

```bash
npm test
```

파서와 로컬 상태 관리의 예시 입력을 검증합니다. 실제 세 서비스의 개인 계정 화면, 로그인 제한, 사이트 레이아웃 변경은 계정 접근이 없어 자동 검증하지 못했습니다. 특히 일부 서비스는 Electron 내장 브라우저의 로그인을 제한할 수 있어 실제 계정으로 확인해야 합니다.
