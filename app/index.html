개인정보 및 기록

Codex·Claude 인증 정보는 각 CLI가 관리합니다. 앱은 사용량 스냅샷만 보관하고, Claude Code 상태줄 데이터는 ~/.usage-see에 저장됩니다. Gemini에서 복사한 텍스트는 읽는 동안에만 사용합니다. Admin API 키를 입력하면 운영체제 보안 저장소로 암호화해 이 기기에만 저장하며, 자체 서버로 전송하지 않습니다.
